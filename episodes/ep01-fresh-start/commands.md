# Commands — EP01

Run these in order. Each block is one step from the episode.

```bash
# 1. Install the bot's libraries (from repo root)
pip install -r requirements.txt

# 2. Add your Alpaca paper keys
cp .env.example .env
#   then paste your key/secret into .env

# 3. Run the bot (from this folder)
cd episodes/ep01-fresh-start
python bot.py
```
