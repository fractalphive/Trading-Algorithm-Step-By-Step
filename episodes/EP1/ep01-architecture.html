DCA Algo — Episode 1 Architecture

From a blank Linux VM to a runnable alpaca-py script that places a paper order for 1 share of SPY

Build sequence (VM)

  • • Fresh Ubuntu VM — nothing installed
  • • apt: python3, pip3, python3-venv
  • • VS Code + Python extension
  • • python3 -m venv myenv & activate

Code path

  • • pip install alpaca-py (in venv)
  • • AI chat writes the script
  • • code.py: TradingClient + order
  • • Runs inside the activated venv

Alpaca paper order

  • • Paper account (free, no real money)
  • • code.py submits 1 SPY market order
  • • Shows as accepted on the paper dashboard
  • • TradingClient via alpaca-py SDK
